ABout the hispire 
HireSphere – Full Stack MERN Recruitment Platform

A modern full-stack MERN recruitment platform for managing job postings, authentication, and applicant workflows with secure JWT authentication and responsive UI.

📌 Project Overview

HireSphere is a full-stack recruitment management platform built using the MERN stack.
The application allows users to register, login securely, manage job postings, and access a personalized dashboard.

The project focuses on:

Secure authentication
RESTful API architecture
CRUD operations
Responsive frontend design
Clean scalable folder structure
